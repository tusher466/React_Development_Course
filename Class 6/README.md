<h1>NexusCore Login Page</h1>

A modern, glassmorphism-inspired login page built with React, Tailwind CSS, and Lucide React icons.

<h3>Features</h3>

1. Fully responsive design

2. "Glassmorphism" UI with backdrop blurs and glowing gradients

3. Custom checkbox and form inputs

4. Show/Hide password toggle

5. Social login layout

<h3>Getting Started</h3>

<b> 1. Install dependencies:</b>

npm install

<b> 2. Run the development server:</b>

npm run dev

<b> 3. Build for production:</b>

npm run build


<h3>Tech Stack</h3>

1. React 18

2. Tailwind CSS

3. Lucide React (Icons)

4. Vite (Build Tool)
